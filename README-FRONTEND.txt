THOMDUCK FRONTEND — GITHUB PAGES

Upload the contents of this folder to the root of your GitHub repository, then enable Settings > Pages > Deploy from a branch > main > /(root).

This is the public frontend only. GitHub Pages cannot run Node.js or securely perform account authentication, admin actions, deposits, withdrawals, balances, rewards, gift codes, or JSONBin writes. Those functions require the separate secure backend package and its environment variables. Do not add secrets to this public repository.

If using a project repository URL (username.github.io/repository-name), test relative asset and service-worker paths after deployment.
